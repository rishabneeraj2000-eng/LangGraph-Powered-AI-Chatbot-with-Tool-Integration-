📌 Project: LangGraph-Powered AI Chatbot with Tool Integration

This project is an AI-powered chatbot built with LangGraph and Google GenAI (Gemini 1.5) that supports multi-turn conversations, tool integration, and persistent chat sessions.

🚀 Features

🔗 Graph-based conversation flow using LangGraph with conditional tool invocation.

🛠️ Integrated tools:

DuckDuckGo Search → Real-time web search.

Stock Price Fetcher → Fetch live stock data via Alpha Vantage API.

Calculator → Perform basic arithmetic operations.

💾 SQLite checkpointing for saving and resuming conversations across threads.

💬 Streamlit frontend with:

Chat streaming functionality (token-by-token AI responses).

Conversation history management.

Multi-thread session handling.

🛠️ Tech Stack

LangGraph (for stateful conversation graph)

LangChain & Google GenAI (Gemini 1.5) (for LLM integration)

Streamlit (for frontend UI)

SQLite (for checkpointing & session persistence)

Python

📂 Use Cases

Conversational AI assistants with external tool support.

Real-time Q&A chatbot with persistent sessions.

Educational demos for LangGraph + tool integration.
